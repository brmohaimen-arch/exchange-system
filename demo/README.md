# بيانات العرض التجريبي (Demo)

قاعدة بيانات **معزولة** ببيانات وهمية واقعية (صرافة ليبية) لتسجيل فيديو العرض أو تجربة النظام أمام عميل.
كل الأسماء وأرقام الهواتف والهويات والحسابات المصرفية مخترعة.

## الأوامر

```powershell
cd demo
python seed_demo.py              # يبني demo\data\sql_app.db (40 يوماً من التاريخ حتى اليوم)
python seed_demo.py --days 60    # تاريخ أطول
python seed_demo.py --seed 7     # توليد مختلف (نفس الرقم = نفس البيانات)
python verify_demo.py            # فحص اتساق الأرصدة والحركات
powershell -ExecutionPolicy Bypass -File start_demo.ps1   # يشغّل الباك إند (8010) والواجهة (3010)
```

ثم افتح <http://localhost:3010>.

إعادة الضبط = شغّل `seed_demo.py` من جديد (أوقف خادم العرض أولاً لأنه يفتح ملف القاعدة).

## الدخول

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `123` | مدير النظام (حساب النظام الأساسي) |

| `treasurer` | `demo123` | مدير الخزينة |
| `accountant` | `demo123` | محاسب |

## ماذا تحتوي

- 4 فروع وخزن (الرئيسية + طرابلس + مصراتة + بنغازي) بأرصدة خمس عملات.
- 4 مصارف و4 حسابات مصرفية للشركة، و16 عميلاً (بعضهم بحسابات مصرفية خاصة).
- نحو 1000 عملية صرافة (شراء/بيع/تبديل) بأسعار تتحرك يومياً، وإيداع/سحب عملاء، وتحويلات بموافقة، وورديات مفتوحة ومغلقة.
- ديون وسلف ومصاريف يومية ووديعة بفائدة.
- ثلاث شركات أسطول (بيان الدولية، الامتياز، اتقن) بمركبات ومعدات وإيرادات ومصروفات وبيع وتقرير ضرر.
- أمثلة جاهزة للتعديل والتراجع: إيداع عميل تحوّل إلى سحب، وإيداع بنكي بمبلغ مصحَّح، وعملية صرافة ملغاة، وسعر مصحَّح، وتحويل بين مصرفين عُكس اتجاهه.
- طلب تحويل معلّق بانتظار الموافقة، وورديات اليوم مفتوحة.

## كيف تعمل (وأمانها)

- التطبيق يفتح `./sql_app.db` بالنسبة لمجلد التشغيل، والسكربت يشغَّل من `demo\data`، فقاعدة الإنتاج/التطوير الأساسية **لا تُفتح ولا تُقرأ ولا تُكتب أبداً**.
- كل شيء يمر عبر واجهة التطبيق البرمجية نفسها (دون إدخال مباشر في الجداول)، فالأرصدة والقيود والكشوف صحيحة كما لو أُنشئت يدوياً؛ الساعة وحدها مُرجَّعة للوراء.
- الاستثناء الوحيد: الرصيد الافتتاحي للمحافظ النقدية في الأسطول يُكتب مباشرة (لا توجد شاشة له، وإدخاله كقيد يُحسب إيراداً).
- لا توجد إعدادات واتساب/تيليجرام/SMS في هذه القاعدة، فلا يُرسل شيء إلى الخارج.
- المجلد `demo\data` مُتجاهَل في git.
